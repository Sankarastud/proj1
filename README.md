# Profit & Loss Generator

A browser-based Profit & Loss statement generator created as a practice project using HTML, CSS, and JavaScript.
## Features
- Add unlimited revenue items
- Add COGS items
- Add operating expenses
- Automatic Gross Profit and Net Profit
- Gross Margin and Net Margin
- Expense breakdown
- INR, USD, EUR and GBP
- Copy statement
- Print / Save as PDF

## Purpose

This project was created to practice:

- Front-end web development
- JavaScript calculations
- Responsive web design
- Git and GitHub
- GitHub Pages deployment

## Note
This is a general management tool, not a substitute for professional accounting advice or statutory financial statements.
